# Catalog reference photos

See [ATTRIBUTION.html](ATTRIBUTION.html) for author, source, license and use per file.
Images were downloaded unchanged from Wikimedia Commons and visually inspected.
CC BY-SA photos retain their licenses; no image content was edited. CSS scales
them with `object-fit: contain`. Reference photos are not claimed to depict
fictional SKU configurations. The page is linked from the storefront footer.

Only ASUS Vivobook 15 uses a clearly labeled family reference photo on its first
gallery image/card. Every exact demo SKU photograph is still missing; the
remaining cards and alternate gallery view use explicit SVG placeholders.

The Lenovo, kettle and keyboard photos are banner imagery only because their
models do not match the Slim 3, ThinkBook, kettle specification or K87 fixtures.
